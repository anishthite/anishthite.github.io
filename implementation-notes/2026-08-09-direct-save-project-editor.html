Summary

Goal
Let the browser editor write project edits directly to js/projects-data.js.
Surface
npm run projects:editor, then open http://127.0.0.1:8088/projects-editor.html.
Source
Existing project catalog file; no database or hosted write path.
Safety
The save server binds to 127.0.0.1, validates project JSON, and writes a backup under .context/project-editor-backups.

Decisions

IDChoice · Rationale
D-001Use a local Node server. A static GitHub Pages page cannot write files by itself.
D-002Keep copy/download fallback. The page remains usable when opened without the local save server.
D-003Write backups before each save. Direct file editing should be reversible without reaching for git reflog.

Definition of done

  • Done · Static fallback still loads.
