Summary

Goal
Make project entries easier to edit and render as individual detail pages.
Surface
project.html?project=<slug> for rendered pages and projects-editor.html for structured editing.
Source
Existing js/projects-data.js; no database or build-time content layer.
Mobile
Editor form and project list collapse to one column.
Open Qs
Whether to expose the editor from public navigation or keep it as a direct utility URL.

Decisions

IDChoice · Rationale
D-001Use one generic renderer instead of generating 39 HTML files. The site is static and already has data-driven project cards.
D-002Keep editing client-side. GitHub Pages cannot write to the repository at runtime, so the editor outputs updated projects-data.js.
D-003Keep the old bespoke template for custom long-form project pages.

Definition of done

  • Done · Project cards open rendered detail pages.
  • Done · Detail pages expose the primary external link and related links.
  • Done · Editor can edit fields and produce a replacement projects-data.js.
  • Done · Syntax, data, DOM smoke, and legacy Gulp checks pass.
